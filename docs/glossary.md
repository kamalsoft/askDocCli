# Glossary

### Authorization
A temporary hold placed on cardholder funds.

### Capture
The process of moving authorized funds to the merchant.

### Settlement
Final transfer of funds between banks.

### Tokenization
Replacing sensitive card data with a non-sensitive token.

### HMAC
Hash-based message authentication code used for request signing.

### Idempotency
Ensures repeated requests produce the same result.

### Webhook
Server-to-server callback notifying merchants of asynchronous events.

### Exception Event
Published when a transaction enters an inconsistent or failed state.
